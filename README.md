# Посмотри в окно

Учебный проект: поиск видео из разных городов с фильтрацией по времени суток.

Репозиторий: https://github.com/trololo1111/posmotri-v-okno-ad

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.
Для загрузки видео требуется интернет и доступ к API Практикума.

## Реализация

- Две колонки с видео, формой поиска и прокручиваемым списком карточек.
- Пользовательские чекбоксы с сохранённым управлением с клавиатуры.
- Состояния наведения, нажатия, видимого фокуса и текущей карточки.
- Стили загрузки и ошибок из заготовки проекта.
- HTML и JavaScript заготовки сохранены; оформление находится в `styles/style.css`.

Десктопная вёрстка рассчитана на ширину окна от 1200 px. На больших экранах
содержимое остаётся по центру. Мобильный макет в предоставленных материалах отсутствует.
